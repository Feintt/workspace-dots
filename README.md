# Workspace Dots

A Noctalia plugin for Hyprland that shows focused, occupied, and empty states for workspaces 1–8.

The community-submission plugin directory is [`workspace-dots/`](workspace-dots/), which contains its manifest, Luau entries, Python event reader, regression tests, screenshot, thumbnail, and user documentation. This is a Noctalia plugin that controls Hyprland through its IPC—not a compiled `hyprpm` plugin.

See [`workspace-dots/README.md`](workspace-dots/README.md) for requirements, installation, behavior, and development tests. The root `catalog.toml` supports using this repository as a standalone Noctalia git source. For a community pull request, submit only the `workspace-dots/` plugin directory; the community repository generates its catalog and requires one plugin per pull request.
